# FASE EXTRA — Cultura em Jogo

Site acadêmico sobre a história e a cultura dos videogames.

## Abrir localmente
Baixe/extraia o pacote da pasta `fase-extra` e abra `index.html` em um navegador. O site tem cinco páginas independentes: Início, Sobre, História, Explore e Contato.

## Recursos
- Layout responsivo para desktop e celular.
- Modo escuro ativado por padrão, com alternância para modo claro e preferência salva no navegador.
- Filtro dos cartões de jogos.
- Validação do formulário (demonstrativo, sem envio de mensagens).
- Perguntas frequentes expansíveis.
- Créditos das fontes e imagens em `LEIA-ME.txt`.

## Publicação
O diretório `source` contém o código do projeto compactado em partes Base64 de um arquivo TAR.XZ. O workflow `.github/workflows/deploy-fase-extra.yml` reconstrói o pacote e publica o site pelo GitHub Pages.
