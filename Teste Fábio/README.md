# Sistema de Notas do Aluno

## Descrição
Este é um pequeno programa desenvolvido em Python que calcula a média aritmética de duas notas inseridas pelo utilizador e determina o estado final do aluno (Aprovado ou Reprovado).

## Funcionalidades
- Solicita ao utilizador a inserção de duas notas (números decimais).
- Calcula a média através de uma função dedicada (`calcular_media`).
- Apresenta a média final formatada com duas casas decimais.
- Avalia o resultado final com base no seguinte critério:
  - **APROVADO!** se a média for igual ou superior a 7.0.
  - **REPROVADO.** se a média for inferior a 7.0.

## Pré-requisitos
Para executar este programa, é necessário ter o [Python](https://www.python.org/downloads/) instalado no computador.

## Como Executar
1. Guarde o ficheiro de código com a extensão `.py` (por exemplo, `sistema_notas.py`).
2. Abra o terminal (ou a linha de comandos) no diretório onde o ficheiro se encontra.
3. Execute o seguinte comando:

```bash
python sistema_notas.py
